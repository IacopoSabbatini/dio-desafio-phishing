# dio-desafio-phishing

Projeto: Análise de Phishing com Kali Linux

Sobre o projeto

Este projeto foi desenvolvido como parte do desafio prático de Cibersegurança da Digital Innovation One (DIO).

O objetivo é estudar técnicas de Engenharia Social e compreender como ataques de Phishing podem utilizar páginas falsas para induzir usuários a fornecer informações confidenciais.

Objetivos

Compreender o funcionamento de ataques de Phishing.

Conhecer a ferramenta Social-Engineer Toolkit (SEToolkit).

Explorar os riscos de páginas falsas de autenticação.

Desenvolver conhecimentos em segurança da informação.

Documentar os procedimentos realizados em laboratório controlado.

Ferramentas utilizadas

Kali Linux

Social-Engineer Toolkit (SEToolkit)

Git e GitHub

Metodologia

O projeto utiliza um ambiente de laboratório controlado para demonstrar os conceitos de Phishing, sem utilizar contas reais ou coletar credenciais de terceiros.

A demonstração utiliza dados fictícios e tem finalidade exclusivamente educacional.

Resultados e aprendizado

Durante o desenvolvimento, foram explorados conceitos de Engenharia Social, identificação de páginas fraudulentas e mecanismos de proteção contra ataques de Phishing.

Como se proteger?

Verificar o endereço dos sites antes de realizar login.

Não acessar links suspeitos.

Utilizar autenticação multifator (MFA).

Não compartilhar senhas.

Utilizar gerenciadores de senhas.

Considerações finais

O projeto permitiu compreender como ataques de Engenharia Social exploram a confiança dos usuários e reforçou a importância da conscientização e das boas práticas de segurança digital.

Projeto desenvolvido para fins educacionais – DIO.
